# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, no harassment. The project is multilingual: write in the language you are comfortable with, and be patient with people writing in their second or third language.

To report unacceptable behaviour, contact the maintainer through [their GitHub profile](https://github.com/zaidlemouakni), or use GitHub's *Report content* option on the comment.
