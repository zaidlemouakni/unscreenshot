# Security

unscreenshot is a set of Python scripts that your AI assistant runs. They read the image you give them and write a `.pptx`. They make no network calls and never execute code taken from the image or the spec.

## Report a vulnerability

Please report it privately through [GitHub's private vulnerability reporting](https://github.com/zaidlemouakni/unscreenshot/security/advisories/new), not in a public issue. Include the steps to reproduce and the version (`metadata.version` in `skills/unscreenshot/SKILL.md`).

## Supported versions

The latest release.
